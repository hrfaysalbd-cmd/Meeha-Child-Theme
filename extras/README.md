# Meeha News: অতিরিক্ত ফাইল

এই ফোল্ডার থিমের অংশ না। এগুলো Meeha News 2.0 থিমের পাশে আলাদাভাবে ব্যবহারের জন্য।

## `photo-frames/`: প্রি-মেইড ফটো ফ্রেম

স্বচ্ছ (transparent) PNG, ফটোকার্ড স্টুডিওর "নতুন ফ্রেম" অপশনে সরাসরি আপলোড করা যায়।
প্রতিটি ফ্রেম দুই মাপে আছে: `1080x1080/` (বর্গ) আর `1080x1350/` (পোর্ট্রেট)। প্রতিটি ফাইল ১ এমবির অনেক নিচে।
সব নকশা কিনারার ৬০ পিক্সেলের ভেতরে বা কোণে রাখা, যাতে মাঝের ছবি ও লেখা ঢাকা না পড়ে।

## `meeha-sample-posts/`: নমুনা পোস্ট প্লাগইন

যে ক্যাটেগরিতে কোনো পোস্ট নেই, সেখানে এক ক্লিকে নমুনা পোস্ট বসায়।

1. `meeha-sample-posts` ফোল্ডারটা জিপ করে Plugins → Add New → Upload দিয়ে ইনস্টল ও Activate করুন।
2. Tools → নমুনা পোস্ট মেনুতে খালি ক্যাটেগরির তালিকা দেখাবে।
3. প্রতি ক্যাটেগরিতে কয়টা পোস্ট (১ থেকে ৬) আর নমুনা ছবি লাগবে কিনা বেছে "নমুনা পোস্ট তৈরি করুন" চাপুন।
4. আসল সংবাদ এলে একই পাতা থেকে "সব নমুনা পোস্ট মুছে ফেলুন" চাপুন। নমুনা ছবিসহ সব মুছে যাবে, আসল পোস্টে হাত পড়বে না।

নমুনা পোস্টের শিরোনামে "নমুনা" লেখা থাকে, আর সার্চ ইঞ্জিনে noindex থাকে (Rank Math থাকলে সেখানেও)। ডিফল্ট ক্যাটেগরি বাদ থাকে।
